# CostGuard: фронтенд (прототип)

Кликабельный прототип интерфейса AI CostGuard: React 19 + TypeScript + Vite, без бэкенда.
Данные синтетические и хранятся в браузере (`localStorage`), все кнопки меняют их.

## Запуск

Нужен Node.js 20+.

```bash
cd apps/frontend
npm install
npm run dev        # http://localhost:3000
npm run build      # проверка типов и сборка в dist/
npm test           # тесты (Vitest + Testing Library)
```

Порт 3000 выбран под клиент `costguard-frontend` в `infra/keycloak/costguard-realm.json`.

## Что внутри

| Раздел | Маршрут | Что можно сделать |
|---|---|---|
| Вход | `/login` | выбрать демо-пользователя одной из 5 ролей Keycloak |
| Обзор | `/` | сводка расходов, согласования, находки, отказы шлюза |
| ИИ-агенты | `/agents`, `/agents/:id` | подключить, изменить, остановить или запустить, выпустить и отозвать ключ, удалить |
| Мандаты и правила | `/policies` | создать, изменить, симулировать на истории операций, опубликовать |
| Согласования | `/approvals` | одобрить или отклонить с комментарием |
| Журнал операций | `/operations`, `/operations/:id` | фильтры, выгрузка CSV, лестница проверок, квитанция, проверка в NEAR |
| Бюджеты | `/budgets` | дерево компания → отдел → агент, изменение лимитов |
| Подписки и договоры | `/software`, `/software/subscriptions/:id` | подписки, договоры, поставщики, назначение и снятие лицензий |
| Техника сотрудников | `/assets`, `/assets/:id` | учёт, выдача с актом приёма-передачи, срок возврата, возврат, списание, вкладка «К возврату», выгрузка CSV |
| Импорт данных | `/imports`, `/imports/:id` | загрузка файла, сопоставление колонок, ручная проверка, отчёт об ошибках |
| Подключённые системы | `/connections`, `/connections/:id` | список систем со статусами, подключение, отключение, синхронизация вручную; меняют только владелец и ИТ-администратор |
| Находки | `/findings`, `/findings/:id` | жизненный цикл по схеме с доски, история, выгрузка CSV |
| Прогнозы и отчёты | `/analytics` | прогноз с диапазоном, сценарий «что если», отчёты XLSX и PDF |
| Оргструктура и доступ | `/org` | отделы, сотрудники, увольнение (создаёт находки по лицензиям и технике), пользователи и роли |
| Уведомления | `/notifications` | список, прочтение, переход к объекту |

Переключатель «Поток событий» в шапке имитирует SSE: раз в 15 секунд приходят новые операции агентов,
отказы по бюджету и запросы на согласование. В меню пользователя есть смена роли и «Сбросить демо-данные».

## Как подключить настоящий бэкенд

- `src/api/types.ts` — типы по модели данных с доски. Их заменит клиент, сгенерированный из
  `schemas/openapi/core.yaml` и `gateway.yaml`, когда спецификации появятся.
- `src/api/store.tsx` — все действия кнопок в одном месте. Каждое действие соответствует будущему
  запросу к REST API, интерфейс функций менять не нужно.
- Акт выдачи техники в прототипе открывается как страница для печати (`actHtml` в `src/pages/Assets.tsx`). С
  настоящим бэкендом кнопка акта скачивает неизменяемый PDF из `GET /api/v1/assets/{id}/assignments/{assignmentId}/act`.
- `src/api/mock-data.ts` — демо-компания, после подключения API удаляется.
- `src/auth/auth.tsx` — имитация Keycloak и права ролей. Меняется на OIDC-клиент (например, `keycloak-js`).
- `simulateTick` в `store.tsx` меняется на подписку `EventSource` на SSE ядра.
