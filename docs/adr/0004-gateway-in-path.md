# 0004. Gateway в пути агента, бюджеты в Redis

## Решение
Агент тратит деньги только через gateway: `/v1/spend/*` для своих покупок и `/v1/providers/*` для LLM.
Решение принимается до траты лестницей проверок: ключ, мандат, петли, риск, бюджет, оценщик, человек.
Счётчики бюджета лежат в Redis и меняются только Lua-скриптами: резерв берёт все уровни сразу или ни одного.
Остальное состояние gateway собирает из компактных топиков в память, к базе ядра он не ходит.

## Последствия
- Падение ядра не останавливает агентов; падение Redis останавливает (fail closed).
- Решения уходят в `agent.operations.v1`, при недоступной Kafka — в файл и позже в Kafka.
