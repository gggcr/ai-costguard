# 0034. Оплата тарифа: интерфейс провайдера и заглушка

## Контекст
Тариф (ADR 0033) оплачивается через провайдера платежей. Провайдер пока не выбран: владелец продукта решит позже
(ЮKassa, Т-Касса, CloudPayments или другой). Нужно, чтобы выбор не потребовал переделывать ядро, и чтобы стенд без
провайдера не раздавал тарифы бесплатно.

## Решение
- **Интерфейс `PaymentProvider`** в модуле `plans` повторяет поток любого эквайринга: `start` создаёт платёж у
  провайдера (id платежа ядра — ключ идемпотентности) и возвращает статус и страницу оплаты; `notice` читает и
  проверяет уведомление провайдера (подпись, отправитель). Непроверенное уведомление ничего не меняет.
- **Оплата.** `POST /api/v1/plan/checkout` (только владелец, работает и в «только чтение»): платёж `pending` пишется в
  `payment`, провайдер вызывается вне транзакции, ответ провайдера записывается. Платёж прошёл сразу — тариф меняется
  сразу; `pending` — клиент получает `confirmationUrl`, тариф меняется по уведомлению на
  `POST /api/v1/payments/notifications/{provider}` (без токена). Уведомление называет только платёж провайдера,
  поэтому компанию находит `payment_ref` (id, без RLS). Повторное уведомление ничего не меняет: двигается только
  платёж в статусе `pending`.
- **Заглушка `DummyPaymentProvider`**: любой платёж проходит сразу, уведомлений не шлёт и не принимает. Включается
  только явно, `PAYMENT_PROVIDER=dummy` (локальный стенд, демо). Пустое значение — оплаты нет, checkout отвечает
  `503 payment_provider_missing`: стенд, где забыли настройку, не отдаст тариф бесплатно. Уведомления принимает только
  настроенный провайдер.
- Ключи провайдера — только из окружения (Vault, Lockbox), в коде и `.env.example` их нет.

## Последствия
- Новая переменная: `PAYMENT_PROVIDER`.
- Подключение реального провайдера: класс, реализующий `PaymentProvider` (проверка подписи уведомлений обязательна,
  чеки по 54-ФЗ — его забота), его ключи в окружении и `PAYMENT_PROVIDER=<имя>`. Ядро и API не меняются.
- Рекуррентных списаний пока нет: каждый месяц — новый checkout. Автопродление зависит от выбранного провайдера.
