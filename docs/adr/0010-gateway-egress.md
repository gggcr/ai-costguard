# 0010. Шлюз: платные внешние API через ту же лестницу проверок

## Контекст
Агенты тратят деньги не только на модели: платные API данных (СПАРК, выписки), облачные API. На доске такие вызовы
идут через шлюз так же, как вызовы моделей, но у них нет токенов и `usage`: цена зависит от того, какой метод API
вызван. Ключ API не должен попадать к агенту.

## Решение
- `/v1/egress/<name>/...` проксируется на API из `costguard.gateway.egress.<name>` (пакет `gateway/egress`) тем же
  `MeteredCallFilter`, что и вызовы моделей: та же `CheckLadder`, резерв до вызова, списание после, возврат при
  ошибке, событие в `agent.operations.v1`. Вид операции — `PAID_API`, продукт метода пишется в поле `model`.
- Цена одного вызова: метод API находится по HTTP-методу и Ant-шаблону пути (`operations`, первый совпавший), иначе
  берутся продукт и цена маршрута. Сначала ищется цена `REQUEST` компании для поставщика и продукта из
  `catalog.prices.v1`, потом `price` из конфигурации. Каталог компании важнее: у компании может быть свой договор.
  Нет ни того ни другого — 403 `price_unknown`, вызов не уходит. Списывается зарезервированная цена: ответ API
  стоимость не сообщает.
- Шлюз снимает с запроса ключ агента (`Authorization`, `x-api-key`) и все заголовки `X-CostGuard-*` и ставит ключ
  API (`header`, `value`). Значение ключа — из переменной окружения или Vault, в репозитории его нет.
- Ошибка API (статус 4xx/5xx или обрыв) после пройденной лестницы записывается как `DENIED` с кодом
  `upstream_error` и фактической стоимостью 0. Так же теперь записываются ошибки провайдеров моделей: путь общий.
  `ALLOWED` с нулём выдал бы квитанцию журнала на несостоявшуюся операцию, а `ALLOWED` без стоимости ClickHouse
  посчитал бы по оценке как трату. Новое значение перечисления `OperationDecision` сломало бы старых читателей.

## Последствия
- Новый платный API — запись в конфигурации и цена в каталоге, без кода.
- В `denied` аналитики попадают и отказы шлюза, и ошибки API; различить их можно по `denial_code`.
- Цена за вызов фиксирована: API с ценой, зависящей от объёма ответа, пока резервируется по верхней цене метода.
