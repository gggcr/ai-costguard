# 0061. Экономия кабинета в рублях

Статус: принято, 2026-11-11.

## Контекст

Пул лицензий (ADR 0055) и проверка покупок (ADR 0056) экономят деньги, но руководство этого не видело.

## Решение

- `GET /api/v1/cabinet/savings?months=12` (owner, finance, it_admin), без новой таблицы — из решений:
  - место выдано из пула (`license_request` granted/approved) — экономия = цена места подписки в месяц
    (годовая / 12); сколько из них забрано у простаивающих;
  - покупка отклонена, потому что программа в компании есть (`purchase_request` has_license) — её сумма в месяц
    (годовая / 12, разовая — один раз). Место, выданное вместо такой покупки, второй раз не считается.
- По месяцам решения (Москва). Цены мест модуль ПО отдаёт через `LicensePool.monthlySeatPrices`.
- Фронтенд: карточка «Экономия от пула лицензий и проверки покупок» над вкладками «Запросов сотрудников».

## Последствия

- Это несделанные траты, а не уменьшение счёта: места подписки остаются купленными, пока ИТ не уменьшит их число.
- Суммы покупок в другой валюте складываются как есть.
