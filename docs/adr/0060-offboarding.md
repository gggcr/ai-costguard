# 0060. Уволили — доступы закрываются сами

Статус: принято, 2026-11-11.

## Контекст

После увольнения (ADR 0059) ящик Microsoft 365 и вход в CostGuard оставались, их закрывали вручную.

## Решение

- `Offboarding` слушает `EmployeeDismissed` (после коммита, как остальные слушатели модулей): по почте сотрудника и
  его пользователей CostGuard отключает учётные записи Keycloak своей компании (`enabled: false`, сессии
  завершаются) и, если компания создаёт почту (ADR 0059) и адрес в её домене, — учётную запись Microsoft 365
  (`accountEnabled: false`, `revokeSignInSessions`).
- Ящик и учётные записи не удаляются: письма нужны для передачи дел, история — для аудита; удаление данных
  сотрудника (ADR privacy) убирает их позже.
- Итог — запись журнала действий `employee.access.closed`, а если Keycloak или Microsoft не ответили —
  `employee.access.close_failed` со списком того, что закрыть вручную.

## Последствия

- Доступы в программах поставщиков (Figma, Adobe…) по-прежнему отзывает ИТ по чек-листу увольнения.
- Приложению Microsoft нужно то же разрешение `User.ReadWrite.All`.
