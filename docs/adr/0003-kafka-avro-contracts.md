# 0003. События — Kafka + Avro, контракты в `schemas/avro`

## Решение
Каждый топик описан файлом `schemas/avro/<topic>.avsc`. Java генерирует из него классы (`libs/java/events`),
Python читает тот же файл (`costguard_common.schemas`), ClickHouse читает те же сообщения форматом
AvroConfluent. Формат на проводе — Schema Registry: байт 0, id схемы, тело.
`libs/python/costguard-common/tests/test_wire.py` сверяет байты Python с байтами Java.

Поле добавляют только со значением по умолчанию, чтобы старые сообщения читались новой схемой.

## Последствия
- Потребители коммитят смещение только после сделанной работы; каждая цель идемпотентна по ключу или id.
  Повторная доставка безопасна, потеря — нет.
- Изменение контракта видно в ревью одного файла.
