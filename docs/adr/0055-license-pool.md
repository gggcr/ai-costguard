# 0055. Пул лицензий: переназначение, а не одалживание

Статус: принято, 2026-11-11.

## Контекст

Пятая часть кабинета (ADR 0051). У одних сотрудников платные программы простаивают, другим они нужны. Первая идея —
«биржа», где сотрудник одалживает свою лицензию коллеге. Решено иначе: общий пул и переназначение лицензий, без
одалживания доступа и без баллов. Доступ к аккаунту не передаётся из рук в руки: лицензию выдаёт компания.

## Решение

- Модуль ПО отдаёт `LicensePool`: лицензии сотрудника, каталог подписок с местами (всего, выдано, свободно,
  простаивает), выдача свободного места, самая простаивающая лицензия подписки, возврат лицензии в пул.
  Простаивающая — без входа `costguard.audit.unused-days` дней (30, как у находки «лицензия не используется») или
  без данных о входе. Свободное место проверяется до выдачи: ошибка внутри общей транзакции пометила бы её на откат.
- Запрос — `license_request` модуля `cabinet`:
  - есть свободное место — лицензия выдаётся сразу (`granted`), сотрудник получает уведомление;
  - иначе запрос ждёт ИТ (`pending`). Если у подписки есть простаивающая лицензия коллеги, запрос это показывает.
    ИТ (owner, it_admin) одобряет: простаивающая лицензия возвращается в пул (её владельцу приходит уведомление:
    «возвращена в общий пул: не использовалась с …»), и место выдаётся просившему. Нет ни свободного места, ни
    простаивающей — одобрить нельзя (409 `no_free_seat`): сначала добавьте места в подписку, или откажите.
- ИТ может разом вернуть в пул все простаивающие лицензии (`POST /api/v1/license-pool/reclaim`).
- Сотрудник видит свои программы, каталог с наличием (без имён коллег) и свои запросы. Отменить можно запрос,
  который ещё ждёт ИТ.
- Фронтенд: вкладка кабинета «Лицензии»; «Запросы сотрудников» → «Лицензии» (finance только смотрит).

## Последствия

- Возврат простаивающей лицензии в CostGuard не отключает её у поставщика: ИТ всё ещё отзывает доступ в самой
  программе (или это сделает коннектор SSO/SCIM).
- Запросы лицензий удаляются вместе с данными сотрудника: учётным документом они не являются.
