# 0053. Отпуска: заявка сотрудника, решение руководителя отдела

Статус: принято, 2026-11-11.

## Контекст

Третья часть кабинета (ADR 0051). Сотрудник запрашивает отпуск на сайте. Решено, что заявку согласует руководитель
его отдела, а кадры (работодатель) видят итог. Руководителя отдела в модели не было.

## Решение

- У отдела появился руководитель: `department.head_employee_id`, `PUT /api/v1/departments/{id}/head` (owner,
  it_admin). Модуль `org` отдаёт `DepartmentHeads`: кто руководитель сотрудника и кем руководит сотрудник.
  Уволенный руководитель заявок не получает.
- Заявка — `vacation_request` модуля `cabinet`. Вид: ежегодный оплачиваемый, без сохранения зарплаты, учебный,
  другой. Дни считаются календарные, как ТК РФ считает ежегодный отпуск. Праздничные дни не вычитаются — это
  упрощение.
- Правила заявки: дата начала не раньше сегодня, конец не раньше начала, нет пересечения со своими заявками. Для
  ежегодного отпуска дней не больше остатка года: 28 минус согласованные и ждущие решения (ТК РФ, ст. 115).
- Руководитель видит заявки своих отделов (`/api/v1/me/team/vacations`) и решает. Чужую заявку и свою собственную
  он решить не может (403 `not_the_head`). Если руководителя нет, решает работодатель: owner, finance, it_admin
  через `/api/v1/vacations`. Он же видит все заявки.
- Сотрудник может отменить заявку, пока по ней нет решения, и согласованный отпуск, пока тот не начался.
- Уведомления личные (ADR 0052): руководителю — «просит отпуск…», сотруднику — «Отпуск согласован / не
  согласован…», руководителю — об отмене согласованного отпуска.
- Фронтенд: вкладка кабинета «Отпуска» (остаток, заявка, свои заявки, заявки отдела для руководителя); вкладка
  оргструктуры «Отпуска» для работодателя (руководители отделов и все заявки).

## Последствия

- Норма 28 дней одна для всех. Дополнительные отпуска (ненормированный день, северные) и перенос остатка с прошлого
  года не учитываются. Нужен будет справочник норм сотрудника.
- Если у отдела нет руководителя, о новой заявке никто не узнаёт уведомлением: работодатель видит её в списке.
