# 0063. Простой лицензий по журналу входов Microsoft

Статус: принято, 2026-11-11.

## Контекст

Лицензия считается простаивающей без входа 30 дней (ADR 0055), но дату входа приходилось загружать файлами. Если
программы подключены к Entra ID через единый вход, Microsoft уже знает, кто и куда входил.

## Решение

- Модуль org отдаёт `MicrosoftSignIns`: последние входы каждого человека в каждое приложение из журнала Microsoft
  Graph `auditLogs/signIns` (только успешные), по приложению компании (ADR 0058/0059, секрет хранится в ядре).
- Кабинет каждое утро (06:30 МСК, `costguard.microsoft.activity-cron`) берёт входы за 3 дня, сопоставляет название
  приложения с подпиской (как покупку, ADR 0062, но без модели) и отмечает лицензию человека с этой почтой
  использованной в тот день (`last_active` не уменьшается). Microsoft 365 — по входам в Teams, Outlook, Office.
- ИТ может загрузить сразу за 30 дней: `POST /api/v1/license-pool/microsoft-activity?days=30` — кнопка
  «Активность из Microsoft 365» в «Запросы сотрудников → Лицензии»; ответ показывает приложения без подписки.

## Последствия

- Приложению нужно разрешение `AuditLog.Read.All` и лицензия Entra ID P1 (журнал входов хранится 30 дней).
- Программы без единого входа через Entra по-прежнему отмечаются из файлов и коннекторов.
- Несколько копий ядра загрузят журнал по разу каждая: результат тот же, лишние запросы к Graph.
