# 0059. Добавил сотрудника — создалась почта и учётная запись; вход кодом вместо пароля

Статус: принято, 2026-11-11. Дополняет ADR 0058.

## Контекст

Ноутбук выдаётся на рабочую учётную запись. Нужно: владелец вводит данные сотрудника — и сразу создаётся рабочая
почта Outlook в Microsoft 365 компании, на неё же — учётная запись CostGuard; пароль придумывается сам. Сотрудник
может подключить Google Authenticator (к приложению можно привязать любую удобную почту) и входить кодом, а не паролем.

## Решение

- `POST /api/v1/employees/onboarding` (owner, it_admin): имя, фамилия, отдел, должность и либо `createMailbox`,
  либо адрес. Порядок: ящик в Microsoft 365 через Microsoft Graph (`POST /v1.0/users`, лицензия
  `assignLicense`, адрес `имя.фамилия@домен` транслитом, занятый — `имя.фамилия2`), затем учётная запись Keycloak
  с паролем, ролью employee и подтверждённой почтой, затем сотрудник и пользователь в ядре. Ошибка на любом шаге —
  созданное раньше удаляется. Пароль один для Outlook и CostGuard, показывается только в ответе.
- Включается владельцем в карточке Microsoft 365: «Создавать почту Outlook», SKU лицензии, страна использования.
  Ядру нужен секрет приложения для Graph: хранится в `company_login.client_secret`, зашифрован AES-256-GCM ключом
  `CONNECTIONS_ENCRYPTION_KEY` (id компании — связанные данные). Без ключа включить нельзя
  (`encryption_key_missing`). Приложению в Entra нужно разрешение приложения `User.ReadWrite.All` с согласием
  администратора.
- Без Microsoft 365 тот же шаг создаёт учётную запись CostGuard на введённый адрес с придуманным паролем.
- Вход в браузере (realm): почта (`auth-username-form`) → пароль **или** код приложения (`auth-password-form` /
  `auth-otp-form`, альтернативы, «Попробовать другой способ»). Код не обязателен: сотрудник подключает приложение в
  личном кабинете («Вход по коду из Google Authenticator» → консоль учётной записи Keycloak) и кнопкой «Входить
  кодом вместо пароля» ставит код первым (`PUT /api/v1/me/sign-in/otp-first` → Keycloak `moveToFirst`). После
  Microsoft код спрашивается, только если приложение подключено. Это заменяет обязательный код из ADR 0058 по
  решению пользователя.

## Последствия

- Код без пароля — один фактор: он защищён тем, что приложение подключается только после входа паролем.
- Ящик и лицензия Microsoft платные; удаление сотрудника в CostGuard ящик в Microsoft 365 не удаляет — это делает
  администратор Microsoft (увольнение — чек-лист).
- Пароль показывается один раз; потерян — сброс в Keycloak (и в Microsoft 365).
