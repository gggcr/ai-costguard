# Вход сотрудников через Microsoft 365

ADR 0058. Сотрудники входят рабочей учётной записью Microsoft и кодом из Google Authenticator.

## Подключить компанию

1. В Microsoft Entra admin center → «Регистрация приложений» → «Новая регистрация»: имя `CostGuard`, тип учётных
   записей — «Только в этом каталоге организации».
2. «URI перенаправления» → «Веб»: адрес из карточки «Вход сотрудников через Microsoft 365» (Оргструктура →
   Пользователи CostGuard), вида `https://<keycloak>/realms/costguard/broker/ms-<id компании>/endpoint`.
3. «Сертификаты и секреты» → новый секрет клиента: скопировать значение (показывается один раз).
4. «Разрешения API»: Microsoft Graph `openid`, `email`, `profile` (делегированные) — по умолчанию уже есть.
5. В CostGuard владелец вводит ID каталога (Directory/tenant ID), ID приложения (Application/client ID), секрет и
   домены почты, нажимает «Подключить».
6. Проверка: выйти, на странице входа ввести рабочую почту — должна открыться страница Microsoft.

## Создание почты при добавлении сотрудника (ADR 0059)

1. В регистрации приложения → «Разрешения API» → «Добавить» → Microsoft Graph → **Разрешения приложения** →
   `User.ReadWrite.All` → «Предоставить согласие администратора».
2. SKU лицензии: Entra → «Лицензии» → «Все продукты», или Graph `GET /v1.0/subscribedSkus` (поле `skuId`).
   Без лицензии пользователь создаётся, но ящика Outlook у него нет.
3. На сервере должен быть `CONNECTIONS_ENCRYPTION_KEY`: им шифруется секрет приложения.
4. В карточке Microsoft 365 включить «Создавать почту Outlook», указать SKU и страну (2 буквы), сохранить
   с секретом клиента.
5. «Оргструктура → Добавить сотрудника»: имя, фамилия, отдел, должность → «Добавить и создать почту». Почта и пароль
   показываются один раз — передать сотруднику.

Ошибка `mailbox_failed` (502) — нет разрешения или согласия, кончились лицензии, неверная страна; подробности в
логе ядра («Mailbox failed»).

## Простой лицензий по входам (ADR 0063)

Разрешение приложения Microsoft Graph `AuditLog.Read.All` (+ согласие администратора), Entra ID P1. Секрет должен
храниться в ядре (сохранить карточку с секретом при заданном `CONNECTIONS_ENCRYPTION_KEY`). Загрузка — каждое утро
и кнопкой «Активность из Microsoft 365» (Запросы сотрудников → Лицензии). Ошибка 502 `microsoft_unavailable` —
нет разрешения или P1.

## Первый вход сотрудника

Учётная запись должна быть (приглашение). При первом входе через Microsoft Keycloak просит подтвердить связь письмом
на почту учётной записи (или её паролем), затем — отсканировать QR в Google Authenticator. Дальше: Microsoft + код.

## Ошибки

- `domain_not_ours` — в компании нет пользователя с почтой в этом домене: сначала пригласите кого-нибудь из него.
- `domain_taken` — домен уже подключён другой компанией: разбирается поддержкой.
- `login_unavailable` (503) — нет связи с Keycloak или у клиента `costguard-registration` нет ролей
  `manage-identity-providers`, `view-identity-providers` (realm-management).
- «Пользователь не найден» после Microsoft — у человека нет учётной записи CostGuard: пригласить.
- Истёк секрет клиента в Entra — создать новый и сохранить карточку с новым секретом.

## Потерян телефон с кодами

Keycloak admin → realm `costguard` → Users → пользователь → Credentials → удалить `otp`. При следующем входе
пользователь настроит приложение заново.
